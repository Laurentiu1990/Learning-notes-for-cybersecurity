# TryHackMe – Pre Security

Completed the **Pre Security** learning path on TryHackMe.

This path helped me build a foundation in cybersecurity and understand the basic concepts behind computers, networks, operating systems, the web, and security.

## What I covered

### Computer & Networking Fundamentals

* Learned the basic components of a computer and how they work together.
* Learned how data is represented and processed.
* Learned the fundamentals of computer networking.
* Learned about IP addresses, MAC addresses, ports and protocols.
* Gained a basic understanding of how devices communicate over a network.

### Networking

* Learned the purpose of common networking protocols.
* Learned the difference between TCP and UDP.
* Learned about DNS and how domain names are resolved.
* Learned the basics of HTTP and HTTPS.
* Became familiar with common network concepts and terminology.

### Linux Fundamentals

* Learned the basics of the Linux operating system.
* Practiced navigating the filesystem using the terminal.
* Learned how to create, modify and remove files and directories.
* Practiced using common Linux commands.
* Learned about permissions and users.

### Windows Fundamentals

* Learned the basic concepts behind Windows systems.
* Became familiar with Windows users, processes and services.
* Learned about the Windows filesystem and basic system administration concepts.

### Web Fundamentals

* Learned how websites and web applications work.
* Learned the basic request/response model.
* Became familiar with HTTP methods and status codes.
* Learned how browsers communicate with web servers.
* Gained a basic understanding of web technologies.

### Cybersecurity Fundamentals

* Learned basic cybersecurity terminology and concepts.
* Learned about common types of vulnerabilities and attacks.
* Started understanding the difference between offensive and defensive security.
* Learned why security needs to be considered at different layers of a system.

## What I took away from the path

After completing Pre Security, I have a better understanding of the foundations that cybersecurity is built on.

The biggest takeaway for me was that cybersecurity is not only about learning hacking tools. Understanding how computers, networks, operating systems and web applications work is essential before trying to understand how they can be attacked or secured.

I also became more comfortable working with the Linux command line and understanding basic networking concepts.
